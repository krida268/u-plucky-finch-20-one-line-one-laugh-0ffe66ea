Try make.fun yourself: https://make.fun/r/enzt809f

## How it works

`main.ts` writes the entry to `/output/entry.txt` (or to the path or
directory given as `argv[2]`), with a guard that the entry is a single
line of 1–200 characters, exactly as the competition gate requires.

```sh
node main.ts
node main.ts /tmp/out.txt
```
